# Test Plan — MediBook Clinic

## Objective

Validate the core user-facing functionality of the MediBook Clinic demo application and confirm that the main doctor-discovery and appointment-booking workflows behave consistently.

## Scope

### In Scope

- Clinic home page
- Navigation
- Specialty browsing
- Doctor discovery
- Doctor search
- Doctor cards
- Doctor profile/details
- Appointment booking
- Date/time selection
- Patient-detail validation
- Booking confirmation
- My Appointments
- Appointment persistence
- Appointment cancellation
- Cancelled appointment removal
- Empty state
- Selected UI states and content checks

### Out of Scope

- Real medical workflows
- Real patient information
- Real payments
- Backend/API testing
- Performance/load testing
- Security/penetration testing
- Cross-browser matrix testing
- Accessibility audit
- Mobile-device matrix testing

## Test Approach

Manual functional testing using positive, negative, consistency, UI, persistence, and end-to-end scenarios.

## Test Data

Only fictional/demo test data was used. No real personal, medical, or payment information was entered.

## Entry Criteria

- Clinic application is accessible.
- Demo environment is available.
- User can navigate to the Clinic area.

## Exit Criteria

- All planned test cases executed.
- Final statuses recorded.
- Evidence captured for key flows.
- Any confirmed defects documented.

## Final Result

All **24 planned test cases** were executed:
- Passed: 24
- Failed: 0
- Blocked: 0
- Not Run: 0

Exit criteria were met.
